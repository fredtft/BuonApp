Guida al Deploy Semplificata

⚠️ IMPORTANTE: Questa è un'applicazione Client-Side (React). Non richiede un server Node.js attivo per funzionare in produzione, ma solo un server web statico (Apache/Nginx). Tuttavia, Node.js serve per "costruire" (build) l'app.

Risoluzione Errore "Killed" (Memoria Insufficiente)

Se ricevi l'errore Killed durante npm install, il tuo server ha finito la RAM. Prova uno di questi comandi:

  1. Installazione leggera (consigliato):
    npm install --omit=optional
  2. Forzare limite memoria:
    NODE_OPTIONS="--max-old-space-size=512" npm install

Passo 1: Pulizia

Accedi al tuo server/FTP nella cartella di destinazione.

Assicurati di avere i file package.json e index.html aggiornati.

Passo 2: Build (Costruzione)

Una volta completato npm install, esegui:

npm run build

Questo creerà una cartella dist/ ottimizzata.

Passo 3: Verifica

Apri il tuo browser all'indirizzo dove hai caricato i file.

L'applicazione dovrebbe caricarsi immediatamente. Se vedi uno schermo bianco, apri la Console (F12) per verificare eventuali errori.
